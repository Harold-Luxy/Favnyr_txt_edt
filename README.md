## What's new?

Now you can right click a .txt/md file and open it as a window of Favnyr.
My favourite way of editing a memo.

**入口**：右键单个 `.txt` / `.md` 文件 → 「在编辑视图中打开」

**能力**：
- 新建一个视图专门编辑该文件
- 标题栏：文件名 + 完整路径 + 脏标记 + 保存按钮 + 移动按钮 + 关闭按钮
- 保存：`Ctrl+S` / 保存按钮 / 失焦自动保存
- 超过 1 MB 的文件拒绝打开
- 同一文件不允许重复打开
- 视图拖动与文件夹视图完全一致（阈值、tooltip、投放区、交换动画）
- 编辑器视图不做「分离为独立窗口」
- 工作区恢复时降级为文件夹视图（文件可能已被删除或改名）
